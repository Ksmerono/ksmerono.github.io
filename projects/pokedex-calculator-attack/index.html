Pokédex — Calculadora de Daño

Tecnologías

ReactViteNode.jsExpressREST APIJavaScriptCSSPokéAPIPythonArquitectura JSON / migración a BD

Descripción

Aplicación web pensada para jugadores de Pokémon competitivo, que permite consultar cualquier Pokémon (1025 especies) junto a sus estadísticas, habilidades, movimientos y cadena evolutiva, y calcular con exactitud el daño de cada ataque.

La calculadora reproduce las fórmulas oficiales del juego: stats con naturaleza e IVs, PS, daño base, y todos los modificadores de STAB, efectividad de tipos, objeto (vidasfera, banda elección, potenciador de tipo) y crítico, permitiendo responder cuestiones como si un ataque debilita en 2 o 3 golpes antes de entrar a la partida.

La arquitectura separa el frontend en React (Vite) de una API REST en Express, que carga los JSON de datos en memoria y los expone como si fueran tablas de una base de datos, resolviendo además relaciones como movimientos e habilidades en cada respuesta.

La capa de datos está aislada en un único módulo, de forma que el proyecto puede migrarse a una base de datos real (PostgreSQL, MongoDB, SQLite...) reimplementando esa capa, sin tocar el frontend.
